# 运行证据目录

- `inputs/`：供实际执行使用的输入，不包含预设输出。
- `cases.json`：场景、资料、故障注入和断言配置。
- `mock/*.json`：实际运行生成的结果，每份含输入、数据摘要、步骤与工具返回。
- `mock/report.json` / `report.md`：自动对比预期和实际结果。
- `mock/test-results.txt`：单元/集成测试命令的实际日志。
- `live/`：当前尚未生成。配置真实模型后运行评估脚本才会产生。

Mock 的分支是规则测试逻辑。虽然 Trace 是程序实际执行记录，它仍然不构成真实模型观察后决策的证据。替换资料时请同时维护合成事实标注；仅修改正文但保留与原文不符的 claim_value 将被数据校验拒绝。
